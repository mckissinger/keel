## The headline answer

The "way longer" feeling has three dominant causes, all structural rather than one-off agent
mistakes: (1) **verification re-runs** — first-pass verifier `discrepancy` is now the norm, and
every base move (rebase, update-branch, remediation) re-runs the full suite even when the
milestone diff is provably unchanged; (2) **the serial runtime substrate** — no per-worktree
stack isolation (Q13 unanswered everywhere), so every `[runtime]` build/verify queues on one
shared local Supabase stack that is itself degraded by *other projects'* stacks; (3) **process
plumbing discovered serially** — stale provisioned scripts, guard/classifier denials at the
merge boundary, and env-posture contradictions each surface one failure at a time, each costing
a diagnose-explain-reroute loop or a human round-trip. The "more issues" feeling is mostly (3)
plus a real cluster of harness/orchestration defects (subagent reports lost, monitors babysat).

## Ranked findings

### F1 — Full-suite re-runs on provably-unchanged code are the top wall-clock sink

**Evidence:** rv-rez e38cc566 (every remediation loop re-runs the whole chain; the flake
root-cause alone consumed ~1h of suite re-runs); cre-list 9be7aa09 (pre-pin runtime walk = 9
serial shard invocations ≈ 3 hours; the e2e-efficiency ask repeated verbatim Jul 21 → Aug 4);
cre-list M88 deep-dive (a one-sentence doc discrepancy forced a full 2360-test re-run on
byte-identical code); Relay 5b97aa9e (post-#88 drift check → sanctioned rebase → full re-suite).
**Diff vs HEAD: partially addressed.** `scripts/repin.sh` mechanizes the carry-forward pin and
`land-feature` documents the cascade, but the rule still requires a *local* green suite re-run
even for conflict-only rebases with an empty milestone-file diff.
**Candidate:** when `git diff <old-pin> <new-tip> -- <milestone files>` is empty, let the PR's
own CI green stand as the re-pin evidence (CI runs the same suites); and add a plan-path fast
lane to the discrepancy rule — a discrepancy confined to `specs/` with code byte-identical to
the walked SHA is fixable and pinnable in the same session without re-running code suites.

### F2 — No runtime isolation contract (Q13): serial everything + cross-project stack contention

**Evidence:** sessionsmith b8ed8899 ("m2 and m3 will build serially… Q13 records no
parallel-session isolation"; 1.5–2h per milestone); rv-rez e38cc566 (fa-2/fa-3 forced serial;
**five Supabase stacks / 55 containers from other projects** found running, causing the
40s-vs-19s suite variance that produced a hydration flake); Relay 1457bc74 (uncapped Playwright
workers vs one stack = recurring flake family until #82); sessionsmith 93166b71-adjacent
(subagent's dirty `config.toml` poisoned sibling milestones' runs).
**Diff vs HEAD: known-open** — this is the unauthored Tier-2 "worktree substrate" item from the
2026-07-29 slate; the field evidence is now overwhelming and it is the largest structural
speed lever keel has.
**Candidate:** author the per-worktree stack isolation contract (ports + config + db per
worktree, or a documented "one stack, N schemas" alternative), plus a stack-hygiene preflight:
before any `[runtime]` run, enumerate foreign project stacks and offer teardown (the Docker
overload was invisible until a user complaint surfaced it).

### F3 — Consuming repos drift from the installed keel version; gaps discovered one merge at a time

**Evidence:** Relay 4fcf851e + sessionsmith 93166b71: arming auto-merge took 3 sequential PRs
each (#92/#93/#94; #58/#59/#60) because provisioned gate scripts predated 1.23.0 splits —
each missing/stale script found only when the next skill step hit it. Relay edcb39c3: "installed

them; plugin reload requires a restart and was asked for in ≥5 sessions across projects.
rv-rez e38cc566 found `check-branch-protection.sh`'s cwd bug live in the field.
**Diff vs HEAD: partially addressed** (the cwd bug is fixed by #210/#211; prep-auto-merge now

**Candidate:** stamp every provisioned script with its keel version; give `status` (and every
skill's preflight that shells a provisioned script) a one-shot "repo scripts match installed
keel X.Y.Z" check whose remedy is ONE batch sync chore PR, not N serial discoveries.

### F4 — Merge-boundary guard/classifier UX: generic denials read as policy stop-points

**Evidence:** the same incident twice independently — rv-rez bf4253fc and sessionsmith
b8ed8899: agent piped `gh pr merge … | tail`, the closed-set whitelist rejected it, and the
deny message ("build sessions never merge…") was indistinguishable from a policy denial → one
premature run-ending stop-point, one wasted user round-trip, ~8-call self-diagnoses. sessionsmith
2eaa7456: user hand-piped fake input into merge-guard.sh to debug a denial that was actually
`allow`. Relay 5b97aa9e: the marker standoff — classifier silently blocked marker writes in auto
mode (no Allow prompt exists there), user typed "I give you explicit permission to merge though"
across ~20 turns before merging by hand.
**Diff vs HEAD: confirmed live** — `guard-branch-rules.sh` emits the generic policy message for
every non-canonical shape; nothing distinguishes "wrong shape" from "no authorization."
**Candidate:** (a) when a marker/mode exists but the shape fails `detect_strict_auto`, the deny
message must say so: "a valid marker exists but the command shape is not the canonical bare
`gh pr merge <pr> --auto` — no pipes, no chaining, no extra flags"; (b) mirror the same hint in
merge-guard.sh; (c) the orchestration skills already say "bare and un-chained" — add it to the
step that *emits* the command in implement-feature/land-feature so the model sees it at the
moment of action.

### F5 — Env-gated live tests: silently skipped in one project, silently spending in another

**Evidence:** sessionsmith b8ed8899/89fa9f7c: `ANTHROPIC_API_KEY` lives in `.env.local`, nothing
loads it into Vitest, so the Q7 "unattended live rung" **silently skipped through an entire
feature's verifications** while reports read green; the classifier denies reading `.env*` at
all, so the rung is structurally unreachable for the agent — a spec-vs-posture contradiction
open since 07-29, producing a false claim the user had to catch ("I'm pretty sure it's
available"). cre-list 9be7aa09: the inverse — Playwright passed the real key to every dev/prod
server, so "no-key" specs made live Opus calls on every suite run (~$47 before the user's
"why did our key spend so much?"). Relay 5b97aa9e: credits topped into the wrong workspace;
the local `.env.local` unfixable by the agent by design.
**Diff vs HEAD: new.** No keel surface requires observing that spec-named tests *executed*, and
provision doesn't prove a sanctioned secret-injection path.
**Candidate:** verify-milestone must treat skip-counts as first-class: every spec-named test is
either observed executing or reported "unmeasured: <cause>" — a skipped live rung can never ride
a green verdict. Provision gains a dry-run of every env-gated rung plus a sanctioned injection
path (allowlisted `with-env`-style runner), so posture and spec stop contradicting. Add the
mirror-image rule: non-`@live` suites must prove the key is *absent* from their env.

## Wins observed (keep these)

- **Fresh-context verifiers and pre-pin security panels repeatedly caught real, shippable
  defects**: redaction egress leak, mirror-image regex bugs, packed-barrel resolution break,
  focus-return a11y defect, unreachable spec arm, false fixture comment (sessionsmith, Relay,
  rv-rez). The 2x verification cost buys real correctness — F1/F9 aim at its *waste*, not its
  existence.
- **Guard discipline held everywhere**: not one session routed around a denial; workarounds
  preserved the protected invariant (Relay's scratchpad commit script with its own HEAD check).
- **The armed auto-merge floor works**: rv-rez PR #10 and cre-list's Aug 5 M88 session landed
  with zero per-merge taps; sessionsmith measured the alternative — 25% of all human input was
  merge taps.
- **Flake-vs-regression adjudication by proof** (baseline worktrees, isolated re-runs,
  markdown-diff natural experiments) repeatedly avoided false remediation.
- **Smooth sessions exist and share a shape**: spec-feature recomposition sessions (rv-rez
  af516ad8, Relay f4786352/15bb351d) and the M88 build ran near-frictionless — the machinery
  works when scripts are current, the stack is quiet, and no secret/merge boundary is crossed.
